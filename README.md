A woodgrain-styled retro Atari multi-cart menu featuring **10 classic Atari-era games** where every originally single-player or alternating-turn hit has been rebuilt for **simultaneous 2-player action**.

## Controls

### Shared Keyboard (Zero-Conflict Layout)
- **Player 1 (Cyan)**: `W A S D` to move/steer/aim • `SPACE` or `F` to fire/jump • `G` / `Q` for Hyperspace
- **Player 2 (Amber)**: `Arrow Keys` to move/steer/aim • `ENTER` or `/` or `R-SHIFT` to fire/jump • `.` for Hyperspace
- **Dual Gamepads**: Plug in 1 or 2 controllers — automatically detected via the browser Gamepad API.
- **Solo Playtesting**: Press `B` (or click **P2: HUMAN**) in-game to toggle a built-in **P2 CPU Bot**.
- **Shortcuts**: `P` Pause • `R` Restart • `ESC` Back to Menu

## Running Locally

Zero build step or dependencies required — open `index.html` directly in your browser, or run:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

> Tip: Enable **GitHub Pages** on the `main` branch (`/` root) to play directly online!
